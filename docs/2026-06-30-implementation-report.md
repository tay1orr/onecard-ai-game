# ONE! 원카드 구현 보고서

## 완성 범위

AI 난이도 3단계와 방 코드 기반 Supabase 2인 온라인 대전을 구현했습니다. AI는 브라우저 내 게임 엔진을, 온라인은 DB의 서버 권위형 RPC를 사용합니다.

## UX 설계

- 첫 화면에서 상대 특징을 읽고 한 번의 선택으로 게임 시작
- 현재 차례, 허용 무늬·숫자, 공격 누적을 중앙에 표시
- 낼 수 없는 카드는 시각적으로 흐리게 처리
- 7 선택 시 손가락으로 누르기 쉬운 2×2 무늬 선택과 `내 패 다시 보기` 제공
- 모바일 손패는 사람이 쥔 듯한 부채꼴과 다량 패 가로 이동을 함께 제공
- 7장 손패는 화면 안에 맞추고, 16장은 식별 가능한 최소 간격을 보장
- 첫 카드와 마지막 카드가 잘리지 않도록 양끝 안전 여백 제공
- 카드 호버 시 위로 솟으며 낼 카드라는 피드백 제공
- 버린 카드 더미에서 플레이어·순서별 카드 기록 확인
- 대기 중 누르고 드래그할 수 있는 젤리·별 팽이·빨간 장미 배치
- 이모지 대신 직접 그린 6종 스티커와 각기 다른 소리·움직임 제공
- AI 대전에서도 플레이어가 스티커를 보내고 AI가 상황·난이도에 맞춰 답장
- 공격·조커·스킵·무늬 변경·원카드에 큰 안내와 파티클 제공
- 카드를 누르면 손패에서 중앙 더미까지 이동한 뒤 상태 갱신
- 새 액션이 발생하면 이전 액션을 즉시 지우고 최신 안내만 재생
- 직접 누르는 양쪽 주사위와 선공·후공 이펙트 제공
- 내가 뽑은 카드를 확인한 뒤 패에 넣는 흐름 제공
- 한 장은 정확히 중앙, 다량 카드는 모바일 가로 슬라이드로 확인
- 주사위 결정 후 셔플하고 상대·나에게 7장씩 번갈아 배분
- 소리 끄기, 규칙, 나가기 버튼을 항상 접근 가능한 위치에 배치
- 애니메이션 감소 환경설정을 존중

## AI 난이도

- 쉬움: 가능한 카드 중 무작위 선택
- 보통: 특수 카드, 남은 같은 무늬 수, 상대 카드 수를 고려
- 어려움: 다음에 이어 낼 카드, 공격 카드 보존, 상대의 원카드 위협까지 추가 평가

AI는 화면을 조작하지 않고 동일한 게임 엔진 API를 사용합니다.

## 온라인 대전

- 회원가입 없이 Supabase 익명 사용자로 접속
- 6자리 방 코드, 호스트·게스트 2인 대기실, 준비 상태
- 준비 완료 재클릭 취소와 같은 방 코드 재대결 신청
- 같은 참가자들이 재대결하는 동안 유지되는 방별 누적 승수
- 양쪽이 각자 주사위를 굴려 서버가 선공 결정
- 주사위 최종 숫자와 선공자를 1.35초 보여준 뒤 카드 배분 시작
- 상대 패는 장수만 공개하고 실제 패와 덱은 비공개 테이블에 보관
- 카드 내기·뽑기·턴·공격·버전 충돌을 RPC에서 검증
- Realtime 상태 갱신과 15초 연결 신호, 이탈 승패 처리
- 새로고침 후 활성 방 자동 복원, 이번 판 카드 기록, 스티커 도배 제한
- 2시간 방 만료 정책과 선택적 자동 정리 SQL 제공

## 검증 결과

- 덱 생성과 배분
- 같은 무늬·숫자 및 7 허용
- 2·A 공격 중에는 2·A·조커를 허용하고 조커 공격은 조커로만 방어
- 공격 누적
- K 연속 턴
- 7 무늬 변경
- 마지막 카드 승리
- AI 카드 및 무늬 선택
- 데스크톱·모바일 레이아웃
- 특수 카드 모달과 AI 턴 전환
- 스크롤 위치 초기화
- 7의 같은 무늬 사용 제한과 선택 무늬 후속 규칙
- 카드 기록 중 AI 일시 정지와 복귀
- 54장 덱과 조커 +5·직전 무늬 유지
- 7 선택 중 패 확인·복귀·내기 취소
- 모바일 부채 각도와 다량 패 간격
- 장난감 경계 제한 이동과 모바일 장미 표시
- 같은 무늬가 아니어도 7 위에 다른 7 허용
- 카드 이동 좌표 계산과 새 액션 우선 교체
- 온라인 닉네임·방 코드·좌석·턴 도우미
- 온라인 비공개 패 RLS, 턴·버전 검증 SQL 정적 검사
- AI·온라인 JavaScript가 참조하는 모든 HTML 요소 ID 대조
- 14장 교차 배분 순서와 재대결 RPC 권한 검사
- 조커 공격 성공 후 자유 내기와 2인전 Q 일반 카드 처리
- 카드 이력·스티커 RPC, 6종 허용 목록, 자동 방 복원 정적 검사
- AI 상황별 스티커 선택·응답 속도·과도한 반응 방지 검사

자동 테스트는 48개입니다. 데스크톱·390×844 모바일에서 드로우 중앙 정렬과 AI 셔플·배분 완료를 실제 브라우저로 확인했습니다. Supabase 익명 사용자 2명으로 준비·취소, 실제 게임 종료, 재대결 신청·취소, 같은 방 코드의 두 번째 주사위와 새 손패 7장까지 서버 통합 검증했습니다. 조커 전용 방어 규칙은 최신 SQL 재실행 후 최종 서버 검증합니다. 배포 후 일반 창과 시크릿 창에서 UI 확인을 권장합니다.
