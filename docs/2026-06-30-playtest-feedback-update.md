# ONE! 원카드 플레이 피드백 반영

## 요청과 반영 결과

1. 카드에 마우스를 올리면 27px 위로 솟고 살짝 확대되며 `내기 ↑` 안내가 나타납니다.
2. 카드 수와 화면 폭에 따라 손패 간격을 동적으로 계산합니다.
3. 데스크톱 16장은 한 화면에 맞추고, 모바일 16장은 숫자가 보이는 42px 간격으로 가로 이동합니다. 양끝 여백으로 첫 장과 마지막 장을 완전히 볼 수 있습니다.
4. 필드의 앞면 카드를 누르면 시작 카드부터 최근 카드까지 플레이어와 순서별 기록을 확인할 수 있습니다.
5. 7은 와일드로 아무 때나 내는 규칙에서, 현재 무늬가 맞을 때만 내고 이후 무늬를 고르는 규칙으로 변경했습니다.
6. 젤리 캐릭터, 별 팽이, 빨간 장미를 추가했습니다. 누르면 각각 다른 표정·회전·흔들기 애니메이션과 짧은 말풍선이 재생됩니다.

## 추가 UX 보완

- 카드 기록을 보는 동안 AI의 행동을 일시 정지합니다.
- 720px 높이 데스크톱에서도 손패 전체가 화면 안에 보이도록 게임판 세로 비율을 조정했습니다.
- 모바일에서도 젤리, 별 팽이, 빨간 장미가 모두 표시됩니다.
- 애니메이션 감소 설정에서는 장난감과 카드 애니메이션을 최소화합니다.

## 검증 기준

- 데스크톱: 1280×720
- 모바일: 390×844
- 자동 테스트: 규칙·조커·7장/16장·부채꼴 레이아웃 22개
- 실제 조작: 난이도 선택, 카드 내기, 기록 열기·닫기, 장난감 클릭
