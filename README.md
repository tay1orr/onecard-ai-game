# ONE! — AI 원카드

설치나 빌드 없이 브라우저에서 바로 실행되는 모바일 우선 원카드 게임입니다.

## 현재 구현

- AI 대전 난이도 3단계: 쉬움, 보통, 어려움
- 52장 카드와 한국식 원카드 간소화 규칙
- 공격 누적, 턴 건너뛰기, 한 번 더, 무늬 변경
- 반응형 모바일·데스크톱 UI와 키보드 접근성
- Web Audio 효과음과 브라우저 내 전적 저장
- 순수 HTML/CSS/JavaScript 모듈 구조

## 로컬 실행

ES 모듈을 사용하므로 파일을 직접 열기보다 간단한 정적 서버로 실행합니다.

```powershell
python -m http.server 8765
```

브라우저에서 `http://localhost:8765/`을 엽니다.

## 파일 구조

```text
index.html              화면 구조와 모달
styles.css              디자인, 애니메이션, 반응형 레이아웃
src/main.js             화면 흐름과 사용자 입력
src/game-engine.js      순수 게임 규칙과 상태
src/ai-player.js        난이도별 AI 의사결정
src/audio.js            설치 없는 Web Audio 효과음
src/2026-06-30-hand-layout.js 손패 수와 화면 폭에 따른 간격 계산
tests/                  게임 규칙 자동 테스트
docs/                   Git·Vercel 인계 문서
vercel.json             정적 배포 설정
```

## 규칙

- 현재 카드와 같은 무늬 또는 같은 숫자를 낼 수 있습니다.
- 7도 현재 무늬와 맞을 때 낼 수 있으며, 낸 뒤 원하는 무늬로 변경합니다.
- 2는 +2, A는 +3 공격이며 2 또는 A로 누적 방어할 수 있습니다.
- J는 상대 턴 건너뛰기, Q와 K는 2인 게임에서 한 번 더 플레이입니다.
- 낼 카드가 없거나 공격을 막지 못하면 카드 더미를 누릅니다.
- 손패를 먼저 모두 비우면 승리합니다.

## 다음 확장 목표

게임 엔진이 화면과 분리되어 있어 방 코드 기반 멀티플레이에서는 상태 전송 계층만 교체할 수 있습니다. 서버리스 실시간 통신 제공자와 방 만료 정책은 멀티플레이 착수 시 결정합니다.
