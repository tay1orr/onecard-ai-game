# ONE! 시즌 2 — 원카드

다섯 AI 상대(나무늘보 루미 · 고양이 미오 · 부엉이 네오 · 늑대 아스트라 · 용 오르비스)나 친구와 1 대 1로 두는 원카드입니다.
시즌 2는 화면 · 카드 · 연출 · 소리 · 꾸미기를 새로 짓고, 시즌 1 기록과 해금은 그대로 이어 갑니다.

## 실행

```powershell
npm install
npm run dev        # 개발 서버
npm run build      # dist/ 로 빌드(Vercel 이 이 명령으로 배포)
npm test           # 규칙 · 기록 · 꾸미기 · 시즌 2 테스트
npm run test:e2e   # 실제 화면 검사(빌드 뒤, 시스템 크롬) — 휴대폰 크기는 node tests/e2e/play.mjs --mobile
```

에셋을 다시 받을 때만: `npm run assets:fetch` → `npm run assets:build`(움직이는 그림까지는 `node scripts/build-assets.mjs .asset-cache public/assets/s2 --animated`). 출처는 [docs/ASSET-CREDITS.md](docs/ASSET-CREDITS.md).

## 시즌 2에서 바뀐 것

- **화면**: 펠트 무대 위 다섯 상대가 서 있는 로비, VS 소개 화면, 3D 주사위, 호두나무 테두리 초록 펠트 탁자, 실제 카드처럼 무늬를 배치한 카드.
- **연출**: 카드가 실제 자리에서 실제 자리로 날아가고(배분 · 내기 · 뽑기), 남은 카드는 미끄러져 자리를 채운다. 조커 · 원카드 · 공격 · 무늬 바꾸기 · 건너뛰기 · 승리는 방송 화면처럼 기울어진 띠와 큰 3D 소품으로 크게 보여 준다. 화면을 누르면 큰 연출을 건너뛴다. 설정에서 연출 줄이기 · 빠르게.
- **연출 순서표**: 카드 이동 → 효과 → 원카드 → 다음 차례가 차례대로 돌아서, 시즌 1처럼 원카드 안내가 빠지거나 효과가 겹치지 않는다.
- **캐릭터**: 상대마다 성격별 대사 · 표정 · 몸짓. 나도 캐릭터(아바타)를 고른다.
- **소리**: Kenney 녹음 소리(카드 · 칩 · 주사위)와 잔음악.
- **꾸미기**: 시즌 1 아이템 87개를 같은 ID · 같은 해금 점수로 모두 새로 그렸고(테마 데이터로 그림), 시즌 2 아이템 30개(내 캐릭터 · 시즌 패스 보상 20개 · 5만 점까지 블랙 오닉스 세트)를 더했다.
- **시즌 패스 · 개막 축제**: 판을 마칠 때마다 경험치, 20단계 보상. 12월 7일까지 경험치 2배 · 보너스판 더 자주.
- **기록 보관**: 동기화를 3방향(지난 동기화 기준점 · 이 브라우저 · 서버)으로 합쳐 패배 점수가 되돌아가지 않는다. 동기화는 판 끝 · 장착 · 화면을 떠날 때만, 로그인 모듈은 필요할 때만 받는다.
- **온라인**: AI 대전과 같은 게임판. 판 버전이 그대로면 다시 받지 않고, 받는 중에 온 알림은 한 번 더 받는다. Supabase 클라이언트 하나. 방을 만들거나 들어갈 때만 익명 로그인.

## 구조

```text

```

## 규칙

- 맨 위 카드와 같은 무늬나 같은 숫자를 낸다. 손패를 먼저 다 내면 이긴다.
- 2는 공격 2장, A는 3장, 조커는 5장. 2 · A · 조커로 이어서 막고, 조커 공격은 조커로만 막는다.
- 상대가 조커 공격을 받으면 조커를 낸 사람은 다음에 아무 카드나 낸다.
- J는 상대 차례를 건너뛴다. 7은 무늬를 바꾸고, 바꾼 뒤에는 그 무늬나 다른 7을 낸다. Q · K는 둘이서 할 때 효과가 없다.
- 이기면 상대 별에 따라 +125~+500점(보너스판 2배), 지면 −50점. 꾸미기는 역대 최고 점수나 시즌 패스 단계로 열리고 다시 잠기지 않는다.
