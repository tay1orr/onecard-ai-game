# ONE! 시즌 2 — 원카드

AI 상대 여덟(나무늘보 루미 · 고양이 미오 · 부엉이 네오 · 늑대 아스트라 · 용 오르비스, 5만 점부터 백조 세레나 · 흑표범 녹턴 · 공작 로제아)나 친구와 1 대 1로 두는 원카드입니다.
시즌 2는 화면 · 카드 · 연출 · 소리 · 꾸미기를 새로 짓고, 시즌 1 기록과 해금은 그대로 이어 갑니다.

## 실행

```powershell
npm install
npm run dev        # 개발 서버
npm run build      # dist/ 로 빌드(Vercel 이 이 명령으로 배포)
npm test           # 규칙 · 기록 · 꾸미기 · 시즌 2 테스트
npm run test:e2e   # 실제 화면 검사(빌드 뒤, 시스템 크롬) — 휴대폰 크기는 node tests/e2e/play.mjs --mobile
```

에셋을 다시 받을 때만: 소리 · 펠트 · 스티커는 `npm run assets:fetch` → `npm run assets:build`, 재질 사진은 `node scripts/fetch-textures.mjs`, 실사 에셋(명화 · 사진 · 누끼 · 시즌 1 그림)은 `.asset-cache/real/` 에 모은 뒤 `node scripts/build-real.mjs` → `node scripts/credits.mjs`(출처 표 · 게임 안 출처 창). 출처는 [docs/ASSET-CREDITS.md](docs/ASSET-CREDITS.md).

## 시즌 2에서 바뀐 것

- **화면**: 펠트 무대 위 다섯 상대가 서 있는 로비, VS 소개 화면, 3D 주사위, 호두나무 테두리 초록 펠트 탁자, 실제 카드처럼 무늬를 배치한 카드.
- **연출**: 카드가 실제 자리에서 실제 자리로 날아가고(배분 · 내기 · 뽑기), 남은 카드는 미끄러져 자리를 채운다. 조커 · 원카드 · 공격 · 무늬 바꾸기 · 건너뛰기 · 승리는 방송 화면처럼 기울어진 띠와 큰 3D 소품으로 크게 보여 준다. 화면을 누르면 큰 연출을 건너뛴다. 설정에서 연출 줄이기 · 빠르게.
- **연출 순서표**: 카드 이동 → 효과 → 원카드 → 다음 차례가 차례대로 돌아서, 시즌 1처럼 원카드 안내가 빠지거나 효과가 겹치지 않는다.
- **캐릭터**: 상대 · 내 캐릭터 모두 실제 동물 사진. 상대마다 성격별 대사와 몸짓.
- **소리**: Kenney 녹음 소리(카드 · 칩 · 주사위)와 잔음악.
- **꾸미기(실사, 11-24)**: 모든 아이템을 실제 에셋으로 — 맵은 위에서 내려다본 꽃 · 테이블 사진 한 장이 곧 판(Pexels · Unsplash · Kaboompics), 맞춤 그림이 필요한 판 · 뒷면 · 앞면 테 · 상대 캐릭터는 GPT 그림(`docs/GPT-그림-프롬프트.md` → `gpt그림/` → `node scripts/build-gpt.mjs`), 카드 뒷면은 명화 · 레두테 장미 도감, 앞면은 실제 옛 카드(영국식 패턴 · 15세기 클로이스터스 카드 · 비스콘티 타로 …), 장난감 · 효과 · 승리는 실물 사진. 시즌 1의 그림 아이템(장미 무도회 · 리얼 로즈가든 · 장미 오르골 · 왕실 꽃정원 분수 …)은 그 그림을 그대로 되살렸다. 시즌 1 아이템 87개는 ID · 해금 점수 그대로.
- **점수 사다리**: 100만 점까지(30만~40만 5천 · 40만~60만 1만 · 60만~100만 1만 5천 점마다 장미 · 꽃 보상). 보관함에 「장미와 꽃」 모아 보기, 시즌 2 첫 방문 때 이미 열린 새 아이템을 한 번 보여 준다.
- **보상 상자(11-24)**: AI 대전이 끝나면 선물 상자 셋 중 하나를 골라 연다. 어느 상자든 점수(그 판 승리 보상의 28%, 지면 12% × 판수 보너스 최대 ×2 × 배수 ×1 · ×2 · ×3 · ×5 · ×10)가 들어 있고, 가끔 상자 전용 아이템(곰 인형 · 귀여운 동물 · 흔하지 않은 디저트 · 장미 아닌 꽃 35종)이 함께 나오며, 고른 뒤 나머지 둘도 열어 보여 준다. 내용은 판이 끝날 때 미리 정해 두고 같은 판은 한 번만 받는다.
- **AI ★6~★8**: 5만 점부터 카드 기억 · 앞수 계산으로 더 센 상대. 상대 패나 덱 순서는 보지 않고(공개된 정보만), 덱도 손대지 않는다 — `tests/ai-strength.mjs` 가 상대 패 · 덱을 가린 얼린 사본으로 확인. 이기면 +700 · +1,000 · +1,400, 지면 −80 · −120 · −160. 친구 대전 보상은 ★5 까지.
- **시즌 패스 · 개막 축제**: 판을 마칠 때마다 경험치, 20단계 보상. 12월 7일까지 경험치 2배 · 보너스판 더 자주.
- **기록 보관**: 동기화를 3방향(지난 동기화 기준점 · 이 브라우저 · 서버)으로 합쳐 패배 점수가 되돌아가지 않는다. 동기화는 판 끝 · 장착 · 화면을 떠날 때만, 로그인 모듈은 필요할 때만 받는다.
- **온라인**: AI 대전과 같은 게임판. 판 버전이 그대로면 다시 받지 않고, 받는 중에 온 알림은 한 번 더 받는다. Supabase 클라이언트 하나. 방을 만들거나 들어갈 때만 익명 로그인.

## 구조

```text
index.html               시작 페이지(Vite)
src/main.js              시작점(글꼴 · 스타일 · 앱)
src/core/                규칙 엔진 · AI · 점수 · 꾸미기 목록 · 미션 · 시즌 패스 · 기록 합치기 · 손패 배치(순수 함수, 테스트 대상)
src/data/                테마(꾸미기 그림 값) · 캐릭터 · 에셋 주소
src/net/                 Supabase 클라이언트 · 기록 동기화 · 온라인 대전
src/ui/                  로비 · VS · 게임판 · 연출 · 결과 · 보관함 · 시즌 패스 · 온라인 · 설정
src/styles/              색 · 글꼴 토큰과 화면별 스타일
public/assets/s2/        줄인 그림(WebP) · 질감 · 사진 · 소리(MP3)
scripts/                 에셋 받기 · 줄이기
supabase/                서버 SQL(시즌 1 그대로) + 시즌 2 선택 SQL
tests/                   규칙 · 시즌 2 테스트, e2e 화면 검사
```

## 규칙

- 맨 위 카드와 같은 무늬나 같은 숫자를 낸다. 손패를 먼저 다 내면 이긴다.
- 2는 공격 2장, A는 3장, 조커는 5장. 2 · A · 조커로 이어서 막고, 조커 공격은 조커로만 막는다.
- 상대가 조커 공격을 받으면 조커를 낸 사람은 다음에 아무 카드나 낸다.
- J는 상대 차례를 건너뛴다. 7은 무늬를 바꾸고, 바꾼 뒤에는 그 무늬나 다른 7을 낸다. Q · K는 둘이서 할 때 효과가 없다.
- 이기면 상대 별에 따라 +125~+500점(보너스판 2배), 지면 −50점. 꾸미기는 역대 최고 점수나 시즌 패스 단계로 열리고 다시 잠기지 않는다.
