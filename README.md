# ONE! — AI·온라인 원카드

설치나 빌드 없이 브라우저에서 바로 실행되는 모바일 우선 원카드 게임입니다.

## 현재 구현

- 점수대별 확률로 만나는 1~5성 AI 자동 매칭과 감속 룰렛 연출
- 승리 시 상대 등급에 따라 +100/+150/+200/+275/+400점, 패배 시 고정 -50점(0점 하한)
- 역대 최고 점수 300~20,000점 구간에서 영구 해금되는 테이블·카드 앞·뒷면·효과·장난감·승리 꾸미기
- 고대 천문대·왕립 필사본·아르데코·석판·청사진·수묵화·타로처럼 카드 전체 인상을 바꾸는 앞뒷면 스킨
- 좌우 폭죽·색종이 대포·초신성·네온 콘서트·벚꽃 소용돌이처럼 화면을 크게 쓰는 승리 피날레
- 전체보기와 실시간 미리보기, 디저트 카페·심해 수족관·네온 아케이드 등 확실히 다른 테마
- 꿈빛 왕국을 포함한 모든 꾸미기는 부위별로 독립 미리보기·장착
- 닉네임과 6자리 방 코드로 참가하는 Supabase 2인 온라인 대전
- 표준 52장과 조커 2장으로 구성된 원카드 규칙
- 공격 누적, 턴 건너뛰기, 한 번 더, 무늬 변경
- 직접 누르는 주사위 선공 결정과 동점 재경기
- 셔플 후 양쪽에 5장씩 번갈아 나눠주는 시작 연출
- 뽑은 카드 중앙 공개·가로 슬라이드, 손패→더미 이동, 새 액션 우선 이펙트
- 준비 완료 취소와 방 코드를 유지하는 온라인 재대결
- AI 경기 종료 후 같은 상대 고정 재대결 없이 새로운 확률 매칭
- 같은 방에서 재대결하는 동안 유지되는 HOST·GUEST 누적 승수
- 방 점수가 초기화돼도 개인 전적 중복 방지가 충돌하지 않는 고유 경기 번호
- 새로고침 뒤 같은 익명 세션과 진행 중인 방 자동 복원
- 버린 카드 더미의 이번 판 기록과 6종 오리지널 스티커 반응
- AI 대전에서 플레이어 스티커와 상황·난이도별 AI 스티커 답장
- 반응형 모바일·데스크톱 UI와 키보드 접근성
- Web Audio 효과음과 브라우저 내 점수·전적 저장(기존 승수·판수 무손실 이전)
- 순수 HTML/CSS/JavaScript 모듈 구조

## 로컬 실행

ES 모듈을 사용하므로 파일을 직접 열기보다 간단한 정적 서버로 실행합니다.

```powershell
python -m http.server 8765
```

브라우저에서 `http://localhost:8765/`을 엽니다.

온라인 대전은 먼저 [Supabase 설정 안내](./docs/2026-06-30-supabase-setup.md)를 따라 프로젝트를 연결한 뒤 `http://localhost:8765/2026-06-30-online.html`에서 테스트합니다.

## 규칙

- 현재 카드와 같은 무늬 또는 같은 숫자를 낼 수 있습니다.
- 7로 무늬가 선언된 상태에서는 선언 무늬 카드 또는 다른 무늬의 7을 낼 수 있습니다. 7을 내면 무늬를 다시 선언합니다.
- 2는 +2, A는 +3이며 2, A, 조커로 누적 방어할 수 있습니다.
- 조커 2장은 무늬와 관계없이 언제든 낼 수 있는 +5 공격 카드이며 조커로만 방어할 수 있습니다. 직전 무늬를 유지하고, 상대가 공격을 받으면 조커를 낸 플레이어는 돌아온 턴에 원하는 카드 한 장을 낼 수 있습니다.
- J는 상대 턴 건너뛰기이며 Q와 K는 2인 게임에서 추가 효과가 없는 일반 카드입니다. K의 두 칸 건너뛰기는 추후 3인 이상 대전에서 적용합니다.
- 낼 카드가 없거나 공격을 막지 못하면 카드 더미를 누릅니다.
- 손패를 먼저 모두 비우면 승리합니다.
- 마지막 한 장이 남으면 `ONE CARD!` 이펙트가 재생됩니다.

## 멀티플레이 보안 구조

온라인 대전은 브라우저가 전체 덱이나 상대 패를 소유하지 않습니다. Supabase RPC가 턴·패·규칙·화면 버전을 검증하고, RLS가 참가 중인 방의 공개 상태만 읽게 합니다. 브라우저 코드에는 Project URL과 Publishable key만 사용하며 Secret/service_role key는 절대 넣지 않습니다.

기존 `onecard-record`의 승수와 판수는 새 점수 프로필로 복사하면서 원본 백업도 별도 보관합니다. 새 결과를 저장할 때도 기존 키를 삭제하지 않고 더 큰 누적값만 반영합니다.

꾸미기는 현재 점수가 아니라 `peakPoints`(역대 최고 점수)로 판정하므로 패배해도 다시 잠기지 않습니다. 기존 사용자는 현재 점수를 최고 점수로 안전하게 이전해 도달 구간 보상을 즉시 받습니다.
